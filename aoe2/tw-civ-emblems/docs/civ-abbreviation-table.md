# 文明縮寫對照表

## 消歧義規則

預設用「常見、一眼就懂」的單一字，優先選一般人熟悉的國名／族名簡稱（英、法、日、中……）；官方名稱沒有慣用單字簡稱的，取官方繁中譯名裡最能辨識的一個字。

兩個文明的預設字撞在一起時，二選一：換一個同樣常見的字（例如 Teutons 不用官方名稱「條頓」的「條」，改用更常見的「德」），或是延伸成 2 個字（例如西班牙用「西」，Sicilians 就不能再用「西」，延伸成「西里」）。

**沒有 3 個字以上的縮寫。** 實測過——把合成好的圖縮到遊戲實際顯示的尺寸（記分板徽章約 28px）看，3 個字在那個尺寸下已經糊成一團，2 個字是上限。

## 透明度

文字疊加層固定 **80%** 不透明度。這個數字不是憑感覺選的：把不同透明度（100%／90%／70%／50%）的成品縮到 28px 比對，70% 以下在小尺寸下已經看不清楚；90% 是實測後認為安全的下限，80% 是在「不要死白一片貼上去」跟「小尺寸還讀得出來」之間取的折衷。
